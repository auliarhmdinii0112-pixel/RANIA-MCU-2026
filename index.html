Master & Firebase

Mode saat ini: Master dan transaksi disimpan di browser menggunakan IndexedDB. Ini aman terhadap refresh pada perangkat yang sama, tetapi belum aman lintas perangkat.

Untuk penyimpanan cloud lintas HP/laptop, masukkan konfigurasi Firebase di bawah. Setelah terhubung, Firestore menjadi sumber data utama.

Jangan masukkan service-account private key. Web Firebase config dapat digunakan di frontend; keamanan data harus ditegakkan dengan Firebase Authentication + Firestore Security Rules.
